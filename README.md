# Projet_ML
Ce projet vise à détecter automatiquement les fraudes bancaires grâce à un modèle de machine learning entraîné sur le jeu de données creditcarddata.csv. Il inclut la préparation des données, l’entraînement, l’évaluation des modèles, leur comparaison, et le déploiement via une API Flask avec une interface utilisateur simple.
